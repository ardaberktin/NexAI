# Nex November 22 activity recognition snapshot

This is the Excalibur server source from the November 22, 2026 deployment that started at 9:25 PM Pacific. Its activity worker, classifier, and brand evidence files match the baseline used in the November 25 activity recognition comparison.

The files under `server/nex/` are the original deployed Python package and its application assets. The archive predates the project's Git history. This snapshot contains the server source available from Excalibur. Apple client source, service configuration, dependencies, and runtime data are outside this snapshot.
